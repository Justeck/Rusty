# Auto Mine

User requested explicit automatic player navigation to a chosen resource and normal mining along the quickest safe route. Previous user instructions authorize autonomous implementation, testing, release, installation and publication. No personal world or public-server action is authorized for this mode; use owned fixtures.

## Design decisions

Native Horizon runtime stays entirely Rust. Add an off-by-default transient Auto Mine module with resource presets (coal, iron, copper, gold, redstone, lapis, diamond, emerald, quartz, nether gold, ancient debris) and a custom resource chosen from the aimed/held registered block. Settings persist; a running session never persists or auto-resumes. Default goal16 blocks, horizontal radius24, limits8..32, health12/20, food10/20, tool durability10%, optional conservative tunnelling and route preview. This is risk minimization, never invulnerability or a claim about unreceived data.

Use a bounded received-terrain snapshot, compact per-cell flags and mining-time estimates, an incremental distance field and time-weighted A* over supported two-block-tall standing positions. Walking plus necessary mining costs determine the lowest estimated route within this finite model. Unknown cells, fluids, dangerous/unstable blocks, unsupported ground, drops over one block and breaking directly under/over the player are rejected. Access digging is restricted to ordinary terrain and selected resources; containers and player-interactive blocks are protected. Revalidate each ordinary move/break against live received terrain. No custom packets, reach changes or hidden information requests.

Use existing host movement and break tasks with exclusive ownership. Stop on manual input/look, menus, focus loss, death/damage, low health/food, full inventory, unsuitable/low-durability tools, denied actions, timeouts, changed world/dimension, unavailable chunks or hazards. Preserve user inputs and restore selected tool only while still owning that selection. Preserve other feature preferences while temporarily suspending conflicting automatic actions. Resource blocks are counted from observed air transitions, not assumed successful clicks.

Provide equivalent Fabric/NeoForge interaction and core tests, retaining their existing server permission policy. Ordinary Java loader integration remains Java; do not introduce JNI or another in-game runtime.

## Review focus

No saved auto-start. No hidden chunk reads. Search work and memory capped. Snapshot paths never bypass live hazard or reach checks. No breaking player supports/containers. Stop owned inputs before next host action on manual takeover. Wrong-tool protection and failed server breaks cannot report success or retry forever. Safe routing takes priority over shortest geometric distance. Outcomes and test coverage remain explicit.
