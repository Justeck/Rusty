Common native requirement: source activation often disables peers and some cleanup derives previous state from assumptions. Use session-tagged leases for movement/look/slot/ability presentation and preserve the actual physical input and latest authoritative state. Every deferred task stops on world leave, death, focus loss, conflicting user input and correction. Numeric source constants describe one engine/version; use the actual host's immutable physics queries for predictions rather than importing those constants wholesale.
