Several modules transmit chat, drafts, translations, API content or teleport commands when actually enabled. Source review does not authorize such transmission; the native implementation must keep local preparation and explicitly configured sending distinct. A disabled feature must cancel or invalidate in-flight async work; clearing visible suggestions alone is not cancellation. GUI/schema validation, component safety and session-aware ownership are practical improvements across these otherwise distinct utilities.
