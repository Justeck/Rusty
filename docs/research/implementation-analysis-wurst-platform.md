| Changelog | Primary action derives an external changelog URL from installed version and appends tracking parameters. | CleanUp | Wrapper opens an operation implemented by `CleanUpScreen`: reverse-iterates saved servers, removes by unknown-host text, protocol mismatch, failed ping, optional name prefix or remove-all; optionally renames every survivor, then saves and rebuilds selection. Failed ping excludes sentinel -2; unresolved detection depends on exact English MOTD text. | Read-only health classification and proposed changes with reversible backup before explicit deletion. Preserve user names by default. Test in-flight ping, temporary DNS failure, translated error text, protocol-compatible proxy, duplicate endpoints, empty list and restoring a backup. Server unavailability is not evidence a bookmark is unwanted. |
| DisableWurst | Wrapper exposes a hide-enable-button checkbox and global enabled state. | HackList | Auto/count/hidden modes, left/right side, fixed/rainbow colors, name/width order, reverse order and animations. HUD keeps identity-based entries, slides/fades over four updates, keeps exiting entries until animation completes, and switches to count if list exceeds available height. Width sorting runs every update because rendered names can change. | Native active-feature HUD derived from actual registry state, text-width cache invalidation and time-based animation. Test rapid off/on, resized display, dynamic suffix width, disabled animation and count excluding exiting entries. The source list-height decision includes animated outgoing entries. |
| Keybinds | Primary action opens a keybind manager preserving previous screen. | LastServer | Empty feature wrapper; `LastServerRememberer` stores one in-memory server object, joins it from multiplayer screen or reconnects through normal connect flow after parsing its address. Test no remembered server, IPv6/port, address changes, disconnect reason and reconnect while a different server is already connecting. |
| NoChatReports | Default disable-signatures checkbox queues a one-shot update on change/login. Replaces one missing-profile-key error with explanatory text and marks otherwise unmarked signed messages reportable. Local integrated server bypasses active mode. | Accurate host chat/security status and normal supported signing controls only; unsigned chat may be refused by server. Test re-enable across disconnect during asynchronous key preparation, server-required signing and message indicators. Changing a local label cannot remove reporting capability from already signed messages. Referenced chat/login/profile-key mixins remain a transitive boundary here. |
| NoTelemetry | Default checkbox enabled; telemetry manager wrapper drops event sends while checked and forwards original event otherwise. It is scoped to that telemetry API, not every network request. | Local opt-out for any Rusty-owned diagnostics, with truthful scope and no telemetry when disabled. Test event factory and delayed sender after preference changes; separately inventory host diagnostics rather than imply a universal network block. |
| Reconnect | Empty wrapper; normal last-server helper and previously reviewed disconnect-screen integration supply behavior. | ServerFinder | Empty descriptive wrapper; no scanner, address source, rate limit or authorization model in this body. | Translations | Default force-English setting; body only exposes checkbox. | Zoom | Default factor3, range1..50, optional wheel on, zoom-in-screens off, validated translation-key binding default V. While held, divides FOV and sensitivity by current factor. High-value practical gaps are exact registry export, global release-on-suspend, contextual keyboard navigation and a truthful connection/security status display. Cosmetic parity does not require recreating reference branding, external services or destructive server-list defaults. Reading all entry bodies does not imply all referenced screens, services or Minecraft mixins have been traced.
