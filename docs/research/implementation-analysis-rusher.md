# RusherHack: individual public contracts and native designs

> Dated reference-mechanism research and design context. Current executable acceptance is recorded only in [Rusty validation](../VALIDATION.md).

On 2026-11-04 all 166 module URLs linked by the official catalogue naming convention were queried through the web tool. 161 returned feature pages; AutoShear, Config, Debug, NoJumpDelay and Notifier were inaccessible. 152 pages exposed a settings section; absence of a section does not prove absence of settings in the product. This is broader than the earlier landing-list inventory. The [setting-path register](implementation-analysis-rusher-settings.json) records factual hierarchy identifiers from command examples; it does not copy documentation prose or proprietary code. Every module below has its own official URL `https://rusherhack.org/features/modules/<Name>.html`, recorded completely in that register.

**Internal algorithms remain unavailable.** The contracts below are public configuration/behavior observations, followed by independently designed native mechanisms and a discriminating test. A documented mode name does not establish how it is implemented or that it works on the pinned Horizon/server. Shared implementation infrastructure can serve related features, but no alternative below is falsely labeled delivered reference parity. This file awards no native acceptance.
