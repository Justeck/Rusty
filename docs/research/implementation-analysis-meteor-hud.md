# Meteor HUD algorithms and native display requirements

> Dated reference-mechanism research and design context. Current executable acceptance is recorded only in [Rusty validation](../VALIDATION.md).

All 15 pinned HUD entry class bodies were read completely on 2026-11-04 at `e3a2e77967629d216e127b5ceecf71fb15f9d2e5`, including the entire 1058-line KeyboardHud with its nested input/CPS/custom-editor classes. Shared HUD renderer, Starscript engine/bindings, inventory/container extraction and entity rendering remain separate dependencies. Source evidence is [HUD elements](https://github.com/MeteorDevelopment/meteor-client/tree/e3a2e77967629d216e127b5ceecf71fb15f9d2e5/src/main/java/meteordevelopment/meteorclient/systems/hud/elements); declared settings and exact file hashes are in the register. No reference assets or source implementation were copied.

| Element | Distinguishing algorithm and configuration | Original native adaptation and individual verification |
|---|---|---|
| active-modules | Rebuilds visible active registry list each tick, sorts alphabetically or by complete rendered width including optional keybind/info suffix. Flat/per-module/rainbow color, auto alignment, scale, background and connected outline quads. Hue progresses by render delta. | Read actual Rusty registry state, cache widths by text/font/scale revision and compute outlines from final rectangles. Test suffix changes, empty/editor placeholder, reverse width cases, long frame and reset of previous-line outline color. |
| armor | Four equipment slots, configurable reversed order/horizontal/vertical, optional empty barrier icon. Damageable stacks show remaining uses or rounded percentage, native bar or none; deferred item drawing. | Snapshot native components and explicit missing slots; avoid divide-by-zero/custom max-damage assumptions. Test unbreakable/custom equipment, empty slots, one remaining use, scale and vertical text overlap. |
| combat | Chooses nearest eligible player within configurable range, rather than necessarily current attacking module's target. Displays model/name/friend/armor-based threat heuristic/ping/distance/visible held+armor enchantments, health and absorption. Absorption chart allocates fixed16 reference maximum. | Target inspector for an explicitly selected or current received entity with field provenance/unknown values. Do not label a weapon holder hostile or infer private inventory. Test nearest changes, friend, missing ping/health, custom max health and absorption above16. Clamp chart to actual domain; server-withheld data stays unknown. |
| compass | Projects four cardinal labels around a circle with sin/cos of wrapped yaw; vertical ellipse factor is sine of clamped pitch+30 degrees. Axis/direction mode, special north color and independent text/compass scale. | Native compass based on actual camera/player orientation with explicit reference. Test cardinal signs, ±180 wrap, vertical look, freecam and resize. This is orientation, not a magnetic/world discovery system. |
| hole | Four neighboring feet-level blocks, relative to cardinal player facing, drawn only when in configured safe-block list; overlays received block destruction progress for each. Does not check floor, headroom or explosion safety here. | Label as surrounding materials; optionally a separately validated shelter classifier using collision/strength rules. Test missing floor, upper opening, fractional player position, unknown neighbor and multiple destruction records. Do not describe four whitelisted walls as guaranteed safety. |
| inventory | Renders 27 main inventory slots; optional held container content chooses offhand before mainhand, includes ender-chest special case delegated to extraction helper. Texture/outline/flat/none backgrounds and scale. | Original native grid from received inventory/component contents only; distinguish observed cache from current container contents. Test empty held container, unsupported component, main/offhand precedence, stale ender cache and count changes. No reference textures. |
| item | Counts a selected item via inventory search; creates display-only stack, hides icon/count or shows zero according to none-mode. Temporarily gives empty display stack count1 so icon can render, then resets. | Read-only count badge separated from real stack mutation; define whether offhand/equipment/container contents count. Test zero, counts beyond stack maximum, custom equivalent IDs, exclusion scope and editor placeholder. |
| keyboard | Movement/click/action/hotbar/full ANSI/ISO/custom layouts; event-driven pressed state and one-second timestamp CPS list. Repeat does not add CPS. Optional fade/HSB color, opacity, border, text fitting. Custom keys serialize binding/label/geometry/CPS, full ISO enter uses special geometry. Native correction is applied only to GUI shortcut key. | Small context-scoped physical-input HUD with bounded per-key rolling buckets and monotonic time. Clear on focus loss and show automated action state separately if desired. Test missing release, repeat, layout rebinding, mouse versus key/scancode, zero/negative/nonfinite imported dimensions and time rollback. Source native-pressed getter appears to compare key identifier rather than actual pressed-state polling; do not reproduce that assumption. Fade alpha interpolation endpoints should match the RGB endpoints. |
| lag-notifier | Uses time since latest observed server tick, hidden below1.1s; colors change at3s and10s. Displays elapsed seconds, not an independent latency or TPS measurement. | Monotonic received-update age with exact source label, reset per connection; optional threshold warning. Test no first tick, paused integrated world, disconnect, packet stall and frame pause. Avoid diagnosing server CPU solely from missing network ticks. |
| map | Selects first held inventory map, configured slot or configured map ID present in inventory; retrieves already received saved map data and calls host map renderer. Scale and optional background. Early no-world tick returns without clearing cached map fields. | Render native received map item/cached payload only if host supports it, keyed to session and dimension. Test slot out of range, stale map after leave, same map ID on another server, absent payload and marker updates. A HUD map is not terrain reconstruction. |
| module-infos | Configured module list shows ON/OFF or enabled module info, with state colors, alignment and two-pixel interline gaps; fallback label for empty list. | Pinned feature status list backed by exact IDs, showing blocked/suspended state separately where applicable. Test unavailable feature after update, changing suffix, empty list and alignment after width change. |
| player-model | Deferred player rendering with interpolated wrapped yaw or explicit yaw, current/custom pitch, optional north/south centering and scale/background. | Native model preview using original host renderer without changing actual entity orientation. Test absent player, interpolation across yaw wrap, custom pitch and render-state restoration after failure. |
| player-radar | Builds received-player list, truncates before distance sort, then filters self/friends during layout/render; distance is camera-relative. Limit truncation clears `[limit-1,size-1)`, retaining last original entry; it does not reliably select nearest configured count. | Filter first, rank by distance with stable ID tie, then truncate, once per update; cap examined rows and expose received scope. Test self/friends among first rows, nearest beyond initial prefix, equal distance, limit1 and freecam. Missing received players cannot be discovered. |
| potion-timers | Filters hidden/ambient effects, formats amplifier+1 and duration using actual world tick rate, caches text each tick. Effect/flat/rainbow colors, border/alignment/scale. | Received-effect timer using native tick semantics and explicit infinite duration; no guessed enemy effects. Test tick-rate change, ambient toggle, hidden-all, expiry and reconnect invalidating prior text. |
| text | Parses/compiles display expression after edits, executes on first render and then at configured tick delay (counter gives delay+1 between regular runs). Catches display runtime errors, renders linked color sections; separate condition compiles and compares output literally to true/false. Text/font/scale changes recalculate geometry. | Original bounded template fields with known data sources and bounded execution if scripting is added. Validate condition syntax just like text, retain last good compiled form or show error, and avoid network/filesystem bindings by default. Test syntax errors in both fields, huge output, missing world, font change, condition returning nonboolean and updateDelay0/4. Starscript's complete language/runtime is not reviewed here. |

The practical shared architecture is an immutable session-scoped HUD snapshot, measured text/cache revisions, and a bounded refresh budget. Displayed claims must name their actual observed quantity: update age, received player, component count or neighboring material. No interface element can supply data the server has not sent.
