# Rusty Java screenshot tour

**39 original captures, grouped by task.** Click any image for the full 1280×720 PNG. These show Fabric 1.3.0-beta.1 on Minecraft 26.3; Fabric and NeoForge share this interface. [Native Horizon gallery](../../README.md) · [Java installation](../../../../java/README.md) · [Capture identities](manifest.json).

The authored courtyard and dark chamber are disposable test fixtures. Screenshots are exact game framebuffer files, with no retouching. Features shown enabled are selected for illustration; only Status HUD starts enabled by default. World tools shown here are in singleplayer; restricted Java tools need explicit server permission in multiplayer. A screenshot illustrates the interface or view and is not a substitute for the [validation report](../../../JAVA_VALIDATION.md).
