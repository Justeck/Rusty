# Local preferences and updates

Rusty stores its feature configuration, local HUD/menu preferences and navigation data under Horizon's per-mod data area for native ID `rusty`. Horizon owns keybindings separately. Use Advanced / Profiles to export/import supported feature presets; local layout/theme preferences remain independent.

Preserve existing player worlds and account data. Changing a native mod set requires rebuilding the client; it does not require deleting worlds or creating duplicate launcher instances. Review source updates and exact host compatibility before installing them. The source URL is resolved to an immutable revision.

The detailed editor and **Options → Mods → Rusty** remain available if a shortcut is cleared. Do not treat unknown preset fields or another client's configuration format as compatible input.
